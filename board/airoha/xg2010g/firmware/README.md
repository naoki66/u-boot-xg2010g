# XG2010G bundled boot firmware inputs

These files are extracted from the XG2010G stock `mtd0` backup dated
2026-08-16 and are used by the GitHub Actions signed `mtd0` workflow.

They are not generated by U-Boot:

| File | Role | Size | SHA256 |
| --- | --- | ---: | --- |
| `mtd0-prefix.bin` | First `0x800` bytes before the FIP in `mtd0` | 2,048 | `82830140f4f8842702d0569065c27071b7cc24e0876e6c487cb4d9d81c294dd7` |
| `ubi-preloader.bin` | BL2 / preloader payload from the stock FIP | 114,548 | `6dfd08d05691cf2d89e0892b4e597a8d9a8ebab80a362c9b7a02868ffcddd1c8` |
| `bl31.bin` | BL31 / EL3 runtime firmware payload from the stock FIP | 41,347 | `e79bb6960e71384a4f8b67be0d0cd0f64042b174b4e6b2502428238f548245f3` |

Use these only for the matching Airoha AN7581-class XG2010G hardware and
NAND/DDR configuration. If the board revision, NAND geometry, DDR layout, or
secure-boot policy differs, extract matching BL2/BL31/prefix files from that
device's own backup and override the workflow inputs.
